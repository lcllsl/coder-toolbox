目标平台：Windows 11 优先

## 1. 文档目的

本文档用于指导 Codex 从零完成“桌面悬浮花瓣工具箱”的设计、开发、测试、打包与交付。Codex 应将本文档视为产品需求说明、交互说明、技术设计约束和验收标准的统一来源。

除非出现无法继续开发的硬性阻塞，不得自行改变以下核心决策：

1. 产品形态是常驻桌面的悬浮球，不是传统主窗口应用。
2. 点击悬浮球后，仅展开第一层“大类花瓣”。
3. 点击大类花瓣后，打开该分类对应的独立功能面板；不再展开第二层功能花瓣。
4. 功能面板中的具体功能可以使用卡片、标签页、分段控件、图标网格等形式，但不得退化为传统后台管理系统式长列表。
5. 整体风格为简约、现代、具备材质感的 Material 风格，强调动效、层级、按压反馈、悬浮反馈和空间连续性。
6. 工具本身不依赖 AI 服务，不需要联网即可完成全部核心功能。
7. 第一版优先支持 Windows 11，不要求第一版同时适配 macOS 与 Linux。
8. 本项目由 Web 前端开发者维护，因此系统能力应尽量通过 Tauri 官方插件和少量封装完成，避免大规模 Rust 业务代码。

## 2. 产品定位

### 2.1 一句话定位

一个常驻桌面边缘、低打扰、打开即用的办公与开发辅助工具箱。

### 2.2 核心价值

本产品不要求用户持续录入计划、维护任务或建立复杂工作流，而是通过以下三类能力直接减少工作中的机械操作：

- 自动运行：健康提醒、剪贴板历史、自动清理。
- 一键处理：JSON、URL、Base64、时间戳、JWT、UUID。
- 快速访问：常用文件夹、临时文件、日期时间、常用网址和应用。

### 2.3 产品原则

所有功能必须至少满足以下一项：

- 无需额外维护即可持续产生价值。
- 可以在 5 秒内完成一次操作。
- 比打开网页、搜索工具或切换多个应用更快。
- 能够自动记录用户原本容易丢失的信息。

以下类型功能不进入第一版：

- 待办事项、日程计划、项目管理。
- 长期笔记、知识库、习惯打卡。
- 复杂文本处理工具。
- OCR、截图、屏幕取色、屏幕标尺、窗口置顶等屏幕工具。
- 云同步、账号系统、团队协作。
- AI 对话、AI 总结或任何依赖模型 API 的功能。

## 3. 第一版功能范围

第一层花瓣仅包含以下五个大类：

1. 健康提醒
2. 剪贴板
3. 开发转换
4. 文件与路径
5. 快捷入口

设置不作为第一层花瓣。设置通过以下入口进入：

- 右键悬浮球菜单中的“设置”。
- 系统托盘菜单中的“设置”。
- 功能面板右上角的设置按钮。

### 3.1 健康提醒

必须实现：

- 起立活动提醒
- 喝水提醒
- 提肛提醒
- 远眺护眼提醒
- 坐姿调整提醒
- 每项提醒独立启用/停用
- 每项提醒独立设置间隔
- 立即完成
- 稍后提醒
- 暂停 30 分钟
- 暂停 1 小时
- 今日不再提醒
- 全局静默模式
- 勿扰时间段
- 今日完成次数统计

默认值：

| 提醒类型 | 默认状态 | 默认间隔 | 稍后提醒 |
|---|---:|---:|---:|
| 起立活动 | 开启 | 50 分钟 | 10 分钟 |
| 喝水 | 开启 | 45 分钟 | 10 分钟 |
| 提肛 | 关闭 | 60 分钟 | 10 分钟 |
| 远眺护眼 | 开启 | 30 分钟 | 5 分钟 |
| 坐姿调整 | 关闭 | 40 分钟 | 10 分钟 |

提醒行为：

- 到点后悬浮球进入对应主题的呼吸发光动画。
- 同时在悬浮球旁弹出轻量提醒卡片。
- 提醒卡片包含图标、标题、简短文案、“完成”“稍后”两个主操作。
- 提醒卡片 30 秒内无操作时自动缩回，但悬浮球保留未处理状态标记。
- 多个提醒同时到达时不得叠加多个卡片，应合并为一张可轮播或汇总卡片。
- 用户点击“完成”后记录完成次数并重置该项计时。
- 用户点击“稍后”后按该项配置延迟，不计完成次数。
- 静默模式只暂停提醒展示，不应删除配置或历史统计。

### 3.2 剪贴板

必须实现：

- 后台自动监听剪贴板变化
- 保存文本内容
- 保存图片内容
- 按日期与时间记录
- 内容去重
- 搜索
- 类型筛选
- 收藏
- 固定
- 一键重新复制
- 删除单条
- 批量删除
- 清空非收藏记录
- 自动清理策略
- 暂停记录
- 敏感内容保护

剪贴板内容类型：

- plain_text
- url
- json
- code
- image
- color
- email
- unknown

图片收录以系统截图流为主要使用场景：用户通过微信、QQ、办公软件或系统截图快捷键完成截图并点击确认后，只要截图工具将位图写入系统剪贴板，本工具应自动收录到图片历史。无需从文件管理器复制图片，也不在第一版重复实现独立截图工具。仅发送或保存文件、未写入系统剪贴板的截图不属于可监听范围。

识别规则只能作为展示标签，不得改变原始内容。

默认保留策略：

- 普通文本：30 天
- 图片：7 天
- 收藏或固定内容：永久保留，直到用户主动删除
- 最大普通记录数：2000 条
- 最大图片记录数：200 条

去重规则：

- 与最近一条记录内容完全相同时，不新增记录，只更新最后使用时间和复制次数。
- 文本按原始字符串哈希去重，不自动 trim，不改变换行。
- 图片按二进制哈希去重。

敏感内容规则：

- 默认通过本地内容规则跳过疑似敏感信息。
- 对疑似密码、验证码、银行卡号、私钥、访问令牌的内容进行本地规则检测。
- 检测到疑似敏感内容时，默认不持久化，仅显示一次“已跳过敏感剪贴板内容”的轻提示。
- 设置中允许用户关闭敏感内容自动跳过，但必须显示风险提示。
- 所有剪贴板数据仅保存到本地，不上传网络。

剪贴板面板布局：

- 顶部为搜索框、类型筛选和“暂停记录”状态。
- 左侧或上部为日期分组导航。
- 主区域使用内容卡片流，不使用传统表格。
- 文本卡片显示最多 6 行预览；图片卡片显示缩略图。
- 卡片悬停显示复制、收藏、固定、删除操作。
- 点击卡片主体复制内容并给予明确成功动效。

### 3.3 开发转换

第一版必须实现六项具体工具：

1. JSON 工具
2. URL 编码/解码
3. Base64 编码/解码
4. 时间戳转换
5. JWT 解析
6. UUID 生成

#### 3.3.1 JSON 工具

功能：

- 格式化
- 压缩
- 校验
- 复制结果
- 输入与输出交换
- 自动从剪贴板填充
- 清空
- 显示错误行列位置
- 支持 2 空格和 4 空格缩进

要求：

- 不修改字符串值。
- 不允许执行输入中的代码。
- 大文本处理时应防止界面卡死；超过 2 MB 时提示并在 Worker 中处理。
- 错误信息必须可读，例如“第 4 行第 18 列附近缺少逗号”。

#### 3.3.2 URL 编码/解码

功能：

- encodeURIComponent 模式
- encodeURI 模式
- 解码
- 查询参数转 JSON
- JSON 转查询参数
- 自动识别当前输入是否已编码
- 复制结果

#### 3.3.3 Base64

功能：

- UTF-8 文本编码
- UTF-8 文本解码
- 图片转 Base64
- Base64 图片预览
- Data URL 与纯 Base64 切换
- 复制结果

要求：

- 对无效 Base64 给出错误提示。
- 图片大小超过 5 MB 时提示用户，仍允许继续但不得冻结界面。

#### 3.3.4 时间戳转换

功能：

- 秒级时间戳转本地时间
- 毫秒级时间戳转本地时间
- 日期时间转秒级时间戳
- 日期时间转毫秒级时间戳
- 显示本地时区
- 显示 UTC
- 一键复制当前时间戳
- 自动判断 10 位或 13 位时间戳

#### 3.3.5 JWT 解析

功能：

- 解析 Header
- 解析 Payload
- 显示 exp、iat、nbf 的可读时间
- 显示是否已过期
- 复制 Header 或 Payload

安全要求：

- 仅解析，不验证签名。
- 页面必须明确提示“解析结果不代表令牌可信”。
- 不发送网络请求。
- JWT 输入不写入普通工具历史；若从剪贴板读取，不得再次创建剪贴板记录。

#### 3.3.6 UUID

功能：

- 生成 UUID v4
- 一次生成 1、5、10、20 个
- 可选去除连字符
- 可选大写
- 一键复制单个或全部

开发转换面板布局：

- 顶部使用图标化工具切换器，不使用纵向菜单列表。
- 当前工具以大卡片形式展示。
- 输入区、操作区和结果区必须有明显空间层级。
- 切换工具时使用滑动、淡入和尺寸过渡，不允许整个面板硬切换闪烁。

### 3.4 文件与路径

必须实现：

- 常用文件夹
- 打开下载目录
- 打开桌面目录
- 打开文档目录
- 打开用户自定义目录
- 拖入文件或文件夹后复制完整路径
- 复制文件名
- 复制父目录路径
- Windows 路径转 Unix 风格
- Unix 风格转 Windows 路径
- 快速创建按日期命名的文件夹
- 临时文件中转区
- 临时文件自动清理

常用文件夹：

- 用户可添加、删除、排序。
- 每项包含名称、路径、专属或默认图标。
- 点击后调用系统文件管理器打开。
- 路径不存在时显示失效状态，禁止静默失败。

路径转换：

- Windows 转 Unix 示例：`C:\Users\demo\file.txt` → `C:/Users/demo/file.txt`。
- 可选转换为 WSL 风格：`C:\Users\demo` → `/mnt/c/Users/demo`。
- Unix 转 Windows 仅对可识别的 `/mnt/<drive>/` 路径执行；无法确定盘符时提示用户。

日期文件夹：

- 默认名称格式：`YYYY-MM-DD`。
- 支持 `YYYYMMDD`、`YYYY-MM-DD_主题`。
- 用户选择父目录后创建并自动打开。
- 重名时不覆盖，显示“文件夹已存在”并允许直接打开。

临时文件中转区：

- 用户可拖入文件或文件夹。
- 工具将内容复制到应用数据目录中的临时区，不移动源文件。
- 显示添加时间、原始路径、大小、过期时间。
- 默认 7 天自动清理。
- 用户可以固定单项，固定后不自动清理。
- 删除时仅删除中转副本，不删除原文件。

### 3.5 快捷入口

必须实现：

- 最近使用功能
- 收藏功能
- 当前日期复制
- 当前时间复制
- 当前日期时间复制
- 当前秒级时间戳复制
- 当前毫秒级时间戳复制
- UUID 快速复制
- 常用网址
- 常用应用
- 全局快捷键呼出或收起悬浮球
- 双击悬浮球自定义动作
- 工作模式
- 静默模式

最近使用：

- 自动维护，不需要用户手动编辑。
- 最多显示 8 项。
- 同一功能重复使用时提升排序。

收藏功能：

- 用户可从任意功能面板点击星标收藏。
- 收藏后在快捷入口中显示。
- 最多 12 项，超出时提示用户先取消其他收藏。

常用网址：

- 用户设置名称、URL、图标或颜色。
- 点击后使用系统默认浏览器打开。
- URL 必须进行协议校验，只允许 http、https。

常用应用：

- 用户通过文件选择器选择可执行文件或快捷方式。
- 点击后启动应用。
- 路径失效时显示失效状态。
- 启动外部程序必须使用受控的 Tauri shell/opener 权限，不允许拼接任意命令。

模式：

- 工作模式：正常记录剪贴板并正常显示提醒。
- 静默模式：继续记录剪贴板，但暂停健康提醒弹卡，仅在悬浮球显示柔和状态点。
- 完全暂停：暂停健康提醒与剪贴板记录；必须由用户明确操作开启。

## 4. 整体交互结构

### 4.1 悬浮球状态

悬浮球至少包含以下状态：

- idle：默认静止状态
- hover：鼠标悬停
- pressed：按下
- dragging：拖动
- snapped：吸附屏幕边缘
- collapsed-edge：贴边半隐藏
- category-open：大类花瓣已展开
- panel-open：功能面板已打开
- reminder-active：存在健康提醒
- paused：完全暂停
- silent：静默模式

### 4.2 悬浮球基础规格

- 默认直径：56 px
- 最小可点击区域：48 × 48 px
- 视觉圆角：50%
- 默认距屏幕边缘：12 px
- 吸附动画：180～260 ms
- 拖动阈值：移动超过 5 px 后判定为拖动，避免误触点击
- 双击间隔：使用系统或 250～350 ms 范围
- 贴边半隐藏：空闲 3 秒后隐藏约 35%，鼠标靠近恢复
- 鼠标悬停：轻微上浮 2 px、阴影增强、图标旋转或位移 4～8 度
- 按下：缩放到 0.92～0.96

### 4.3 第一层大类花瓣

点击悬浮球时，只展开五个大类花瓣：

- 健康提醒
- 剪贴板
- 开发转换
- 文件与路径
- 快捷入口

每个花瓣必须包含：

- 专属图标
- 简短分类名称
- 独立主题辅助色
- 悬停反馈
- 按下反馈
- 展开和收回动画

推荐主题色：

| 分类 | 建议辅助色 | 图标语义 |
|---|---|---|
| 健康提醒 | 青绿色 | 心跳、水滴或叶片 |
| 剪贴板 | 蓝紫色 | 剪贴板或叠层卡片 |
| 开发转换 | 琥珀色 | 代码括号或魔方 |
| 文件与路径 | 靛蓝色 | 文件夹或路径节点 |
| 快捷入口 | 珊瑚橙 | 闪电或火箭 |

颜色只作为点缀，不允许大面积高饱和填充。

### 4.4 花瓣布局算法

花瓣以悬浮球为中心，按当前屏幕可用空间自动选择展开方向。

规则：

1. 悬浮球位于屏幕右半侧时，花瓣向左侧半圆或扇形展开。
2. 位于左半侧时，向右侧展开。
3. 靠近顶部时，优先向下展开。
4. 靠近底部时，优先向上展开。
5. 多显示器环境中，以悬浮球当前所在显示器的工作区计算，不得使用主显示器尺寸代替。
6. 花瓣与屏幕边缘至少保留 12 px 安全距离。
7. 花瓣之间不得重叠，标签不得被裁切。

建议参数：

- 花瓣中心距主球中心：88～112 px
- 五个花瓣分布角度：约 120～170 度扇形
- 单个花瓣视觉尺寸：52～64 px 图标主体，带标签时整体宽度约 88～112 px
- 动画错峰：每个花瓣延迟 35～55 ms

### 4.5 大类花瓣动画

展开过程：

1. 主球压缩至 0.92。
2. 主球内部图标旋转或形变为关闭符号。
3. 花瓣从主球中心缩放 0.3、透明度 0 开始。
4. 沿弧线路径向目标位置移动。
5. 通过轻微弹簧回弹到最终位置。
6. 标签在按钮到位后 60～100 ms 淡入。

收回过程按相反顺序执行，但总时长略短。

建议动画时长：

- 展开：360～480 ms
- 收回：260～360 ms
- 花瓣悬停：140～180 ms
- 花瓣按下：80～120 ms

### 4.6 点击大类后的行为

点击大类花瓣后：

1. 被点击花瓣执行按压和聚焦动效。
2. 其余花瓣向主球中心收回并淡出。
3. 被点击花瓣沿弧线靠近功能面板出现位置。
4. 功能面板从该花瓣位置展开，形成空间连续感。
5. 悬浮球继续保留在原位置，并切换为“返回/关闭”视觉状态。
6. 功能面板打开后，不再显示该分类下的功能花瓣。

### 4.7 功能面板

功能面板不是传统应用主窗口，应保持悬浮、轻量、具备材质层级。

通用要求：

- 圆角：18～24 px
- 阴影柔和且具有层级
- 支持浅色和深色主题
- 顶部包含分类图标、标题、收藏/设置/关闭等操作
- 内容区域根据功能自适应
- 面板尺寸不得超过当前显示器工作区的 80%
- 面板打开位置优先靠近悬浮球，同时避免越界
- 支持拖动面板，但不要求改变悬浮球位置
- 点击面板外部时默认不自动关闭，避免输入中误触丢失；点击悬浮球或关闭按钮关闭

推荐默认尺寸：

| 分类 | 默认宽度 | 默认高度 |
|---|---:|---:|
| 健康提醒 | 520 px | 560 px |
| 剪贴板 | 680 px | 720 px |
| 开发转换 | 760 px | 620 px |
| 文件与路径 | 620 px | 620 px |
| 快捷入口 | 560 px | 540 px |

窗口尺寸应在小屏幕上自动缩小并允许内部滚动。

### 4.8 关闭与返回逻辑

- 花瓣展开状态下点击悬浮球：收回所有花瓣。
- 面板打开状态下点击悬浮球：关闭面板并回到仅悬浮球状态。
- 面板中的返回按钮：关闭面板并重新展开第一层大类花瓣。
- Esc：优先关闭当前弹窗；无弹窗时关闭功能面板；仅花瓣展开时收回花瓣。
- 系统托盘“显示/隐藏”：切换悬浮球可见状态。

#### orb-window

负责：

- 无边框
- 透明背景

- 默认不可调整大小

- 避免扩大透明区域后拦截桌面点击。

- 花瓣与面板可独立处理焦点和生命周期。

## 9. 剪贴板监听设计

### 9.1 实现策略

第一版允许使用后台轮询实现稳定跨平台行为，Windows 优先。

推荐：

- 轮询间隔：700 ms，可在 500～1000 ms 内调整。
- 应用完全暂停时停止轮询。
- 读取到内容后计算哈希，与最后记录比较。
- 写回剪贴板时设置内部忽略标志，避免本工具自己的复制动作重复入库。
- 剪贴板读取异常不得导致主进程崩溃。

后续可以在 Windows 使用原生剪贴板事件监听优化，但不是第一版硬性要求。

### 9.2 性能要求

- 空闲状态 CPU 占用应尽可能低，目标低于 1%。
- 不得每次轮询都查询完整数据库。
- 图片只在内容变化后读取完整数据。
- 图片保存为应用数据目录中的文件，数据库只保存路径与元数据。
- 数据清理作为低优先级后台任务，每日一次或启动时执行。

## 10. 健康提醒调度设计

### 10.1 调度规则

- 以系统时间为准。
- 设备睡眠后恢复时，不补发所有错过提醒，只触发当前最优先的一项并重新计算后续时间。
- 用户修改间隔后立即重新计算 nextTriggerAt。
- 今日不再提醒只持续到本地日期变化。
- 勿扰时段内不展示；勿扰结束后重新计算，不集中补发。

### 10.2 优先级

同时到达时优先级：

1. 起立活动
2. 远眺护眼
3. 喝水
4. 坐姿调整
5. 提肛

允许合并展示，但完成操作必须分别记录。

## 11. 安全与隐私

必须满足：

- 默认离线运行。
- 不包含遥测、统计上传和广告。
- 不上传剪贴板、文件路径、JWT 或任何用户内容。
- 数据库存放在 Tauri 应用数据目录。
- 敏感剪贴板内容默认跳过。
- 外部网址只允许 http/https。
- 外部应用启动禁止执行用户拼接的 shell 字符串。
- 文件删除仅限应用临时目录和应用自身生成文件。
- 不得删除用户原始文件。
- Tauri capability 采用最小权限原则。
- 日志不得打印完整剪贴板内容、JWT、文件二进制和用户隐私数据。

提供“清除全部本地数据”按钮，执行前二次确认。清除内容包括：

- 剪贴板历史
- 剪贴板图片缓存
- 提醒统计
- 临时文件副本
- 最近使用记录

保留或重置设置应由用户在确认框中选择。

- 静默模式

- 设置

## 15. 错误处理

## 16. 性能指标

目标：

- 冷启动到悬浮球可见：3 秒以内
- 点击悬浮球到花瓣动画开始：100 ms 以内
- 功能面板打开：500 ms 内完成视觉展开
- 普通 JSON 处理：100 ms 内
- 1 MB JSON 处理：1 秒以内
- 剪贴板搜索 2000 条记录：300 ms 内返回
- 空闲内存目标：尽量控制在 120 MB 以内
- 空闲 CPU：尽量低于 1%

性能指标是目标，不得为了满足数字牺牲稳定性，但明显超出时必须分析原因。

## 19. 验收标准

只有同时满足以下条件，第一版才可视为完成：

### 产品

- 悬浮球可长期常驻。
- 第一层只展开五个大类花瓣。
- 点击大类后直接打开该分类功能面板。
- 不存在传统左侧菜单 + 右侧表格式主界面。

### 交互

- 所有点击均有视觉反馈。
- 花瓣展开、收回和面板切换流畅。
- 拖动与点击不会互相误触。
- 屏幕边缘和多显示器下不越界。
- 动画期间不会产生重复窗口或错乱状态。

### 视觉

- 具备统一图标、色彩、圆角、阴影和动效系统。
- 浅色与深色主题完整。
- 界面不是临时 Demo 或浏览器默认控件拼接。
- 所有面板均达到可正式使用的视觉完成度。

### 功能

- 健康提醒稳定运行。
- 剪贴板文本和图片记录可搜索、复制、收藏、清理。
- 六项开发转换完整。
- 文件与路径工具可用。
- 快捷入口、全局快捷键、开机启动可用。

### 隐私

- 无网络依赖。
- 无数据上传。
- 敏感内容默认跳过。
- 日志不泄露用户内容。
- 可一键清除本地数据。

### 工程

- TypeScript 无明显类型逃逸。
- 关键逻辑有测试。
- 项目可在全新 Windows 11 环境按 README 构建。
- 可生成 Windows 安装包。
- 不存在必须依赖开发者机器绝对路径的配置。

## 21. Codex 执行规则

Codex 在开发过程中必须遵守：

1. 先读取并维护项目根目录 `AGENTS.md`。
2. 将本文档复制到项目 `docs/product-spec.md`，保持为产品事实来源。
3. 以阶段为单位开发，每阶段完成后更新 `docs/progress.md`。
4. 不得未经说明更换 Vue、Tauri 或数据库技术栈。
5. 不得将悬浮花瓣交互改为普通菜单、抽屉或列表。
6. 不得删除动画以换取实现简单，但必须提供 reduced-motion 降级。
7. 不得为了快速完成而使用在线接口处理剪贴板或转换数据。
8. 任何系统权限必须在 capabilities 中显式、最小化配置。
9. 新增依赖前确认必要性，避免同时引入多个功能重复的 UI 或动画库。
10. 每阶段运行与该阶段相关的测试，不要求每次修改都运行全部耗时测试。
11. 出现平台限制时，优先保证 Windows 11 完整可用，并在已知问题中记录其他平台差异。
12. 不得伪造已通过的测试或打包结果。

## 24. 最终开发目标

最终应用应让用户产生以下体验：

- 平时几乎感受不到它的存在。
- 需要时，悬浮球就在桌面边缘。
- 点击后，五个大类花瓣以流畅、有质感的方式展开。
- 点击一个分类后，功能面板自然从该花瓣位置生长出来。
- 使用任一功能都能在极少步骤内完成。
- 剪贴板和提醒无需用户维护即可持续工作。
- 工具美观、顺手、低打扰，不像后台系统，也不像功能堆砌的传统工具箱。

这就是第一版所有设计、开发和验收工作的最终判断标准。
