# 花瓣工具箱用户说明

## 启动与退出

开发环境执行 `pnpm tauri dev`。macOS 构建产物可直接打开 `src-tauri/target/release/bundle/macos/花瓣工具箱.app`。

关闭功能面板不会退出应用。需要结束后台进程时，请使用系统托盘中的“退出”，或进入设置 → 数据与应用 → 退出应用。

## 悬浮球

- 单击展开五个分类花瓣，再单击收回；展开后应用失焦也会自动收回。
- 拖动悬浮球可吸附到屏幕四边，空闲 3 秒后会带动画半隐藏，悬停时恢复。
- 设置中可调整尺寸与透明度，也可为双击指定快捷入口、剪贴板或开发转换。
- 默认全局快捷键为 `Ctrl+Alt+Space`。若与其他软件冲突，可在设置 → 行为中修改。

## 五类功能

- 健康提醒：配置起立、喝水、提肛、护眼和坐姿提醒；支持勿扰、稍后、调试触发与完成统计。
- 剪贴板：自动记录文本和图片，支持搜索、筛选、收藏、固定、预览和清理。敏感内容默认跳过；文件列表、来源应用和排除应用不在当前范围。
- 开发转换：提供 JSON、URL、Base64、时间戳、JWT 解析和 UUID 生成，所有转换均在本机完成。
- 文件与路径：常用位置、Windows/Unix/WSL 路径转换、日期文件夹和临时中转。临时中转只删除应用副本，不删除原文件。
- 快捷入口：快捷复制日期时间等常用值，展示最近使用与收藏，并管理可编辑的常用网址和应用。

## 运行模式

- 工作模式：记录剪贴板并正常展示健康提醒。
- 静默模式：继续记录剪贴板，暂停健康提醒弹卡。
- 完全暂停：暂停健康提醒展示和剪贴板记录。

三种模式可从设置或系统托盘切换，重新启动后仍会保留。

## 数据与隐私

应用默认离线运行，不包含遥测、广告或用户内容上传。剪贴板历史、提醒统计、设置和临时副本只保存在 Tauri 应用私有目录。

设置 → 数据与应用提供两种清理方式：

- 清除数据并保留设置：删除剪贴板历史与图片缓存、提醒统计、临时中转副本和最近使用，保留主题、收藏、常用入口、快捷键和提醒配置。
- 清除数据并重置设置：在上述清理基础上恢复全部默认设置，并关闭开机启动。

两种操作都不会删除用户原始文件，执行前均需二次确认。

## 常见问题

- 截图没有进入历史：确认截图工具已把图片写入系统剪贴板，并检查是否开启了“暂停记录”或“完全暂停”。
- 健康提醒没有弹出：检查运行模式、全局静默、勿扰时段和对应提醒开关；可用每项的“调试”按钮立即预览。
- 全局快捷键无效：该组合可能被系统或其他应用占用，请至少使用两个修饰键后重新设置。
- 开机启动设置失败：开发模式或受限制的系统环境可能不允许注册，请使用打包后的应用重试。
- macOS 首次打开被拦截：当前开发包未进行公证签名，仅用于本机测试；正式分发前需要开发者签名和公证。

## 当前平台限制

macOS 开发版已经完成构建与自动化验证。Windows 11 x64 仍是第一版正式验收平台，安装包、透明窗口命中、多显示器缩放、全局快捷键、开机启动和外部应用启动必须在 Windows 实机复验。
